CP++ Error Documentation
========================

This file documents the native CP++ diagnostics currently produced before
falling back to generated C++ compiler errors.

General syntax
--------------

missing semicolon
  A CP++ statement must end with a semicolon.

  Example:
    print("hello")

  Diagnostic:
    error: missing semicolon

unsupported statement
  The statement is not recognized by the current compiler frontend.
  At the moment, supported statements are primitive declarations,
  assignment statements, print(...) calls, if/else blocks, while loops,
  for loops, and rep loops.

  Example:
    doThing();

  Diagnostic:
    error: unsupported statement

Primitive type errors
---------------------

expected variable name after <type>
  A primitive declaration must provide a valid identifier after the type.

  Example:
    int = 5;

  Diagnostic:
    error: expected variable name after int

variable '<name>' is already declared
  A variable name cannot be declared twice in the same current scope.

  Example:
    int x;
    int x;

  Diagnostic:
    error: variable 'x' is already declared

expected value after '='
  A declaration assignment has an equals sign but no value.

  Example:
    int x =;

  Diagnostic:
    error: expected value after '='

expected ';' or '=' after variable name
  Extra tokens appeared after a variable name in a declaration.

  Example:
    int x y;

  Diagnostic:
    error: expected ';' or '=' after variable name

expected variable name after ','
  A comma-separated declaration list must include a variable name after
  every comma.

  Example:
    int a,;

  Diagnostic:
    error: expected variable name after ','

int requires an integer literal
  CP++ int declarations accept integer literals and arithmetic expressions.
  Non-arithmetic literal values are rejected.

  Example:
    int x = 1.5;

  Diagnostic:
    error: int requires an integer literal

integer literal overflows CP++ int
  CP++ int is a 64-bit signed integer. Literal values outside that range
  are rejected.

  Example:
    int n = 100000000000000000000000000000000;

  Diagnostic:
    error: integer literal overflows CP++ int

removed bigint and bigfloat types
  bigint and bigfloat have been removed from CP++. Use int or float instead.

  Example:
    bigint x = 123;

  Diagnostic:
    error: bigint has been removed from CP++; use int or float instead

char values must be a single character in single quotes
  char literals must use single quotes and contain exactly one character.

  Example:
    char c = "B";

  Diagnostic:
    error: char values must be a single character in single quotes

unterminated char literal
  A char literal starts with a single quote but does not close.

  Example:
    char c = 'B;

  Diagnostic:
    error: unterminated char literal

unexpected characters after char literal
  Extra characters appeared after a valid char literal.

  Example:
    char c = 'B's;

  Diagnostic:
    error: unexpected characters after char literal

char literal contains too many characters
  A char literal contains more than one character.

  Example:
    char c = 'AB';

  Diagnostic:
    error: char literal contains too many characters

Print errors
------------

unclosed parenthesis in print
  A print call starts with print( but does not close its argument list.

  Example:
    print(x;

  Diagnostic:
    error: unclosed parenthesis in print

empty print argument
  A print call has an empty argument.

  Example:
    print(x, );

  Diagnostic:
    error: empty print argument

unterminated string literal in print
  A print argument starts a string literal but does not close it.

  Example:
    print("hello);

  Diagnostic:
    error: unterminated string literal in print

expected ',' between print arguments
  Print arguments must be separated with commas.

  Example:
    print(wrote char);

  Diagnostic:
    error: expected ',' between print arguments

use of undeclared variable '<name>'
  A bare identifier passed to print must refer to a declared variable.

  Example:
    print(wrote);

  Diagnostic:
    error: use of undeclared variable 'wrote'

expected ',' before flush
  Deprecated. Use end = flush instead of passing flush as a print argument.

  Example:
    print("answer" flush);

  Diagnostic:
    error: use end = flush instead of flush argument

end must be the final print option
  The end option controls how a print call ends and must appear after all
  printable values.

  Example:
    print("x", end = " ", 1);

  Diagnostic:
    error: end must be the final print option

print end must be a string, char, or flush
  print end accepts a string, a char, or flush. end = flush emits a newline
  and flushes the stream.

  Example:
    print("x", end = 1);

  Diagnostic:
    error: print end must be a string, char, or flush

print requires at least one value
  print must receive at least one printable value before any end option.

  Example:
    print(end = " ");

  Diagnostic:
    error: print requires at least one value

print end option
  print ends with a newline by default. The end option changes the ending.
  end = flush means newline plus flush.

  Example:
    print("hi");
    print("hi", end = " ");
    print("hi", end = flush);

empty print
  print() is allowed and emits a single newline.

  Example:
    print();

describe
  describe prints the variable name followed by its value.

  Example:
    int x = 3;
    describe(x);

  Output:
    x: 3

describe requires a single variable
  describe accepts exactly one variable, not a literal or expression.

  Example:
    describe(x + 1);

  Diagnostic:
    error: describe requires a single variable

Expression and assignment errors
--------------------------------

use of undeclared variable '<name>'
  Arithmetic expressions and assignments must reference declared variables.

  Example:
    int x = missing + 1;

  Diagnostic:
    error: use of undeclared variable 'missing'

expected expression
  An arithmetic operator or assignment has no expression where one is required.

  Example:
    int x = 1 +;

  Diagnostic:
    error: expected expression

unexpected token in expression
  Extra tokens appeared after a complete expression.

  Example:
    int x = 1 2;

  Diagnostic:
    error: unexpected token in expression

unclosed parenthesis in expression
  An expression starts a parenthesized group but does not close it.

  Example:
    int x = (1 + 2;

  Diagnostic:
    error: unclosed parenthesis in expression

expected expression after assignment
  An assignment operator has no value after it.

  Example:
    x +=;

  Diagnostic:
    error: expected expression after assignment

multi-declaration requires the same number of values as variables
  A comma-separated declaration with comma-separated initializers must provide
  exactly one value for each declared variable.

  Example:
    int a,b = 1,2,3;

  Diagnostic:
    error: multi-declaration requires the same number of values as variables

multi-assignment requires the same number of values as targets
  A comma-separated assignment must provide exactly one value for each target,
  unless the right side is input(), which reads one value per target.

  Example:
    int a,b;
    a,b = 1,2,3;

  Diagnostic:
    error: multi-assignment requires the same number of values as targets

cannot implicitly convert <from> to <to>
  Numeric narrowing conversions and bigint/float branch conversions require
  an explicit cast.

  Example:
    int x = 1;
    char y = x;

  Diagnostic:
    error: cannot implicitly convert int to char

Operator support
----------------

shift operators
  << and >> are supported for int, char, and bool expression operands.
  The result is an int value.

  Example:
    int shifted = 1 << 4;

bitwise operators
  &, |, and ^ are supported for int, char, and bool expression operands.
  The result is an int value.

  Example:
    int flags = 5 & 3;

boolean operators
  &&, ||, and ! are supported for CP++ value expressions. The result is bool.

  Example:
    bool ok = true && !false;

compound assignment operators
  CP++ supports compound assignment forms for supported binary operators,
  including +=, -=, *=, /=, %=, <<=, >>=, &=, |=, ^=, &&=, and ||=.

  Example:
    int flags = 1;
    flags <<= 3;
    flags ^= 2;
    bool ok = true;
    ok &&= flags > 0;

increment and decrement operators
  ++ and -- are supported in prefix and postfix form for mutable char, int,
  and float variables. They can be used as statements or inside expressions,
  including if and while conditions.

  Example:
    int n = 3;
    while (n--) {
        print(n);
    }

    ++n;

comparison operators
  <, <=, >, >=, ==, and != are supported for int, float, char, and bool
  values. int and float values can be compared with each other.

  Example:
    bool less = 1 < 2;
    bool same = 'A' == 'A';
    float f = 1.5;
    bool lessFloat = f < 2.0;

cannot use '<operator>' with <left> and <right>
  An operator was used with operand types that CP++ does not support.

  Example:
    float f = 1.2;
    int bad = f & 3;

  Diagnostic:
    error: cannot use '&' with float and int

cannot use '++' with <type>
  Increment and decrement operators require a mutable numeric or char
  variable. bool cannot be incremented or decremented.

  Example:
    bool ok = true;
    ok++;

  Diagnostic:
    error: cannot use '++' with bool

expected variable before '++'
  Postfix increment and decrement must be applied to a mutable variable.

  Example:
    1++;

  Diagnostic:
    error: expected variable before '++'

expected variable after '++'
  Prefix increment and decrement must be followed by a mutable variable.

  Example:
    ++1;

  Diagnostic:
    error: expected variable after '++'

cannot compare <left> and <right>
  The two operand types cannot be compared by CP++.

  Example:
    bool bad = "x" < 2;

  Diagnostic:
    error: cannot compare unknown and int

Control flow
------------

if, else if, else, while, for, and rep blocks
  CP++ supports C++-style if, else if, else, while, and for block outlines,
  plus rep(count). Conditions must be bool expressions or values that can be
  implicitly converted to bool, and block bodies use normal CP++ statements.

  Example:
    int a = 1;
    int b = 2;
    if (a < b) {
        print(a);
    } else if (a == b) {
        print(0);
    } else {
        print(b);
    }

    while (a < b) {
        a = a + 1;
    }

    for (int i = 0; i < 3; i++) {
        print(i);
    }

    rep(3) {
        print("again");
    }

expected condition
  An if or else if block has an empty condition.

  Example:
    if () {
        print(1);
    }

  Diagnostic:
    error: expected condition

if condition must be bool
  if and else if conditions must produce bool or a value that can be
  implicitly converted to bool. int and bigint convert as 0 -> false and
  nonzero -> true. char converts as '\0' -> false and any other character
  -> true. float and bigfloat convert as 0 or NaN -> false and any other
  value -> true.

  Example:
    if ("not supported") {
        print(1);
    }

  Diagnostic:
    error: if condition must be bool

while condition must be bool
  while conditions follow the same bool conversion rules as if conditions.

  Example:
    while ("not supported") {
        print(1);
    }

  Diagnostic:
    error: while condition must be bool

for condition must be bool
  for loop conditions follow the same bool conversion rules as if conditions.

  Example:
    for (int i = 0; "bad"; i++) {
        print(i);
    }

  Diagnostic:
    error: for condition must be bool

expected rep count
  rep requires a count expression inside parentheses.

  Example:
    rep() {
        print(1);
    }

  Diagnostic:
    error: expected rep count

rep count must be numeric
  rep count must be a numeric or char/bool value.

  Example:
    rep("bad") {
        print(1);
    }

  Diagnostic:
    error: rep count must be numeric

else without matching if
  An else or else if block must immediately follow a completed if or else if
  block.

  Example:
    else {
        print(1);
    }

  Diagnostic:
    error: else without matching if

unmatched closing brace
  A closing brace appeared without a matching open if, else if, or else block.

  Example:
    }

  Diagnostic:
    error: unmatched closing brace

unclosed block
  An if, else if, or else block was opened but not closed before the end of
  the file.

  Example:
    if (true) {
        print(1);

  Diagnostic:
    error: unclosed block

Input
-----

input()
  input() is target-typed by declarations and assignments. It reads one value
  from standard input using the destination type. In multi-declarations and
  multi-assignments, one input value is read for each destination variable.

  Example:
    int x = input();
    x = input();

    int a,b,c = input();
    a,b,c = input();

input must be called as input()
  input is a built-in input call, not a variable name. It must include the
  empty parenthesized call.

  Example:
    int x = input;

  Diagnostic:
    error: input must be called as input()

input() does not take arguments
  input() is target-typed by the destination variable, so it does not accept
  arguments inside the parentheses.

  Example:
    int x = input(123);

  Diagnostic:
    error: input() does not take arguments

unclosed parenthesis in input
  An input call starts with input( but does not close the call.

  Example:
    int x = input(;

  Diagnostic:
    error: unclosed parenthesis in input

input() can only be used as the entire value in an assignment or declaration
  input() cannot currently be embedded inside an expression because its type
  comes from the assignment or declaration target.

  Example:
    int x = input() + 3;

  Diagnostic:
    error: input() can only be used as the entire value in an assignment or declaration

multi-assignment requires input()
  A comma-separated assignment can only read multiple values with input().

  Example:
    int a,b;
    a,b = 1;

  Diagnostic:
    error: multi-assignment requires input()

illegal operation on type
  An assignment expressions with illega;l types

  Example:
    (3 + "hi");
  
  Diagnostic:
    error: cannot add dissimilar types.

Runtime errors
--------------

runtime diagnostic model
  CP++ has two runtime-oriented compilation targets. --run emits checked C++
  for readable CP++ runtime diagnostics and catches those errors in generated
  main. --submit emits lean C++ for submission and does not add readable
  runtime-error checks. Both modes otherwise lower the same CP++ program.

  Example:
    int total=18;
    int zero=0;
    int x=total/zero;

  Diagnostic:
    error: runtime error: division by zero

division by zero
  In --run mode, integer division by zero is checked and reported as a readable
  CP++ runtime error. In --submit mode, division is emitted as ordinary C++.

  Example:
    int numerator=12;
    int denominator=0;
    int answer=numerator/denominator;

  Diagnostic:
    error: runtime error: division by zero

modulo by zero
  In --run mode, integer modulo by zero is checked and reported as a readable
  CP++ runtime error. In --submit mode, modulo is emitted as ordinary C++.

  Example:
    int x = 4 % 0;

  Diagnostic:
    error: runtime error: modulo by zero

integer overflow
  In --run mode, integer +, -, *, and the LLONG_MIN / -1 and LLONG_MIN % -1
  cases are checked and reported as readable integer overflow diagnostics. In
  --submit mode, arithmetic is emitted as ordinary C++.

  Example:
    int x = 9223372036854775807;
    x = x + 1;

  Diagnostic:
    error: runtime error: integer overflow

Whitespace-insensitive parsing
------------------------------

lexer whitespace
  The lexer skips whitespace and does not emit whitespace tokens. Parser
  decisions should be made from tokens, not from the amount of space between
  tokens.

  Example:
    int x=8;
    int y=2;
    int z=(x+y)*3/2%7;
    print(z);

for-header semicolons
  Semicolons inside for(...) headers are part of the header, not statement
  separators. This works even when the header has no spaces.

  Example:
    for(int i=0;i<3;i++){
    print(i);
    }

block brace whitespace
  Control-flow opening braces may appear on the same line as the header or on
  their own line. Empty blocks such as if(true){} are accepted.

  Example:
    if(true){}
    while(n<2)
    {
    n++;
    }

empty condition
  Flexible block brace placement does not make an empty condition valid.

  Example:
    if()
    {
    print(1);
    }

  Diagnostic:
    error: expected condition

Multiple statements per line
----------------------------

semicolon-separated statements
  Multiple semicolon-terminated statements may appear on the same physical
  source line and are lowered as separate C++ statements.

  Example:
    int a = 0; int b = 1; print(a,b);
