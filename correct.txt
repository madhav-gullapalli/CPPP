CP++ Correctness Documentation
==============================

This file documents correctly written CP++ programs and snippets that should
compile or run successfully.

Declarations
------------

primitive int declaration
  int declarations compile.

  Example:
    int x = 3;

primitive float declaration
  float declarations compile.

  Example:
    float x = 2.5;

primitive char declaration
  char declarations compile.

  Example:
    char c = 'x';

primitive bool declaration
  bool declarations compile.

  Example:
    bool ok = true;

string declaration
  string declarations compile.

  Example:
    string s = "hello";

list int declaration
  List<int> declarations compile.

  Example:
    List<int> values;

nested list declaration
  Nested Lists compile.

  Example:
    List<List<int>> grid;

multiple declarations
  Multiple variables may be declared together.

  Example:
    int a,b = 1,2;

int reassignment
  ints may be reassigned.

  Example:
    int x = 1;
    x = 2;

float reassignment
  floats may be reassigned.

  Example:
    float x = 1.0;
    x = 2.5;

bool reassignment
  bools may be reassigned.

  Example:
    bool ok = false;
    ok = true;

string reassignment
  strings may be reassigned.

  Example:
    string s = "a";
    s = "b";

arithmetic assignment
  arithmetic expressions may initialize ints.

  Example:
    int x = 1 + 2 * 3;

cast assignment
  explicit casts compile.

  Example:
    int x = 65;
    char c = char(x);

set cast from list
  Set(list) removes duplicates and stores the values in sorted order.

  Example:
    List<int> values = [4, 1, 4, 2];
    Set<int> seen = Set(values);
    print(seen);

  Output:
    {1, 2, 4}

list cast from set
  List(set) keeps the Set iteration order.

  Example:
    Set<int> seen = {4, 1, 2};
    List<int> values = List(seen);
    print(values);

  Output:
    [1, 2, 4]

map cast from pair list
  Map(pairs) converts a List<Pair<K, V>> into a Map.

  Example:
    List<Pair<int, int>> entries = [(3, 9), (1, 4)];
    Map<int, int> counts = Map(entries);
    print(counts);

  Output:
    {1:4, 3:9}

pair list cast from map
  List(map) converts a Map into sorted key/value pairs.

  Example:
    Map<int, int> counts = {3:9, 1:4};
    List<Pair<int, int>> entries = List(counts);
    print(entries);

  Output:
    [(1,4), (3,9)]

string conversions for scalar values
  string(x) works on scalar CP++ values.

  Example:
    print(string(7));
    print(string(true));
    print(string('x'));
    print(string(2.5));

  Output:
    7
    1
    x
    2.5

scalar conversions from string
  Primitive values can be reconstructed from valid string representations.

  Example:
    print(int("-12"));
    print(bool("true"), bool("0"));
    print(char("z"));
    print(float("1"), float("1.5"));

  Output:
    -12
    1 0
    z
    1 1.5

combined scalar and container conversions
  Scalar and container casts can be combined in one flow.

  Example:
    List<int> nums = [1, 2, 2, 5];
    Set<int> seen = Set(nums);
    List<int> ordered = List(seen);
    Map<int, int> counts = Map([(1, int("3")), (4, int(string(len(ordered))))]);
    print(string(len(ordered)));
    print(ordered);
    print(List(counts));

  Output:
    3
    [1, 2, 5]
    [(1,3), (4,3)]

range declarations
  `range` values are lazy integer iterables that can be stored in variables.

  Example:
    range up = range(5);
    range down = range(5, 1);
    range stepped = range(2, 11, 3);
    print(List(up));
    print(List(down));
    print(List(stepped));

  Output:
    [0, 1, 2, 3, 4]
    [5, 4, 3, 2]
    [2, 5, 8]

membership in ranges
  `in` checks range membership with arithmetic, not by building a List.

  Example:
    print(3 in range(5), 5 in range(5));
    print(3 in range(5, 1), 1 in range(5, 1));
    print(8 in range(2, 11, 3), 9 in range(2, 11, 3));

  Output:
    1 0
    1 0
    1 0

foreach on ranges
  `for (... in range(...))` iterates ascending, descending, and stepped ranges.

  Example:
    for (int x in range(4)) {
        print(x, end = " ");
    }
    print("");
    for (int x in range(4, 1)) {
        print(x, end = " ");
    }
    print("");
    for (int x in range(2, 11, 3)) {
        print(x, end = " ");
    }
    print("");

  Output:
    0 1 2 3 
    4 3 2 
    2 5 8 

convert ranges to List and Set
  `List(range)` and `Set(range)` materialize the lazy values when needed.

  Example:
    print(List(range(5)));
    print(Set(range(5, 1)));
    print(List(range(2, 11, 3)));
    print(Set(range(2, 11, 3)));

  Output:
    [0, 1, 2, 3, 4]
    {2, 3, 4, 5}
    [2, 5, 8]
    {2, 5, 8}

empty ranges
  `range(x, x)` is empty for membership, loops, and conversions.

  Example:
    int hits = 0;
    for (int x in range(4, 4)) {
        hits++;
    }
    print(3 in range(4, 4), hits);
    print(List(range(4, 4)));

  Output:
    0 0
    []

nested casts
  Scalar casts may still be nested inside other expressions.

  Example:
    int y = int(float("1.23"));
    print(y);

  Output:
    1

large range membership
  Huge ranges still support O(1) membership tests.

  Example:
    if (3 in range(1, 12345678765432)) {
        print(1);
    } else {
        print(0);
    }

  Output:
    1

default values output
  Declarations use CP++ defaults.

  Example:
    int x;
    float y;
    bool ok;
    print(x, y, ok);

  Output:
    0 0 0

Printing
--------

print int output
  print(int) outputs the value.

  Example:
    print(7);

  Output:
    7

print string output
  print(string) outputs normal text.

  Example:
    string s = "hello";
    print(s);

  Output:
    hello

print string literal output
  print(string literal) outputs normal text.

  Example:
    print("hello");

  Output:
    hello

print list output
  print(List) uses bracketed formatting.

  Example:
    List<int> values = [1, 2];
    print(values);

  Output:
    [1, 2]

Linear data structure declarations
  Stack, Queue, and Deque are generic heap-backed collections that default to
  empty and print in List order.

  Example:
    Stack<int> stack;
    Queue<int> queue;
    Deque<int> deque;
    print(stack, queue, deque);

  Output:
    [] [] []

Stack operations
  Stack.add(...) pushes at the top. top() peeks and pop() returns and removes
  that same element.

  Example:
    Stack<int> stack = Stack([1, 2]);
    stack.add(3);
    print(stack, stack.top(), stack.pop(), stack);

  Output:
    [1, 2, 3] 3 3 [1, 2]

Queue operations
  Queue.add(...) enqueues at the back. top() peeks and pop() removes from the
  front.

  Example:
    Queue<int> queue = Queue([1, 2]);
    queue.add(3);
    print(queue, queue.top(), queue.pop(), queue);

  Output:
    [1, 2, 3] 1 1 [2, 3]

Deque operations
  A Deque supports constant-time access, insertion, and removal at both ends.

  Example:
    Deque<int> deque = Deque([2, 3]);
    deque.addFront(1);
    deque.addBack(4);
    print(deque, deque.front(), deque.back());
    print(deque.popFront(), deque.popBack(), deque);

  Output:
    [1, 2, 3, 4] 1 4
    1 4 [2, 3]

Linear data structure lengths
  len(...) is O(1) for Stack, Queue, and Deque.

  Example:
    Stack<int> stack;
    Queue<int> queue;
    Deque<int> deque;
    stack.add(1);
    queue.add(2);
    deque.addFront(3);
    deque.addBack(4);
    print(stack, queue, deque);
    print(len(stack), len(queue), len(deque));

  Output:
    [1] [2] [3, 4]
    1 1 2

List to linear data structure conversions
  Stack(...), Queue(...), and Deque(...) convert a compatible List in O(n).

  Example:
    List<int> values = [1, 2, 3];
    Stack<int> stack = Stack(values);
    Queue<int> queue = Queue(values);
    Deque<int> deque = Deque(values);
    print(stack, queue, deque);

  Output:
    [1, 2, 3] [1, 2, 3] [1, 2, 3]

Linear data structure to List conversions
  List(...) materializes Stack, Queue, or Deque contents in their printed order.

  Example:
    Stack<int> stack = Stack([1, 2, 3]);
    Queue<int> queue = Queue([4, 5, 6]);
    Deque<int> deque = Deque([7, 8, 9]);
    print(stack, queue, deque);
    print(List(stack), List(queue), List(deque));

  Output:
    [1, 2, 3] [4, 5, 6] [7, 8, 9]
    [1, 2, 3] [4, 5, 6] [7, 8, 9]

Stack of custom classes
  Linear data structures can contain custom class values.

  Example:
    class Point {
        int x;
        int y;
    }
    Stack<Point> points;
    points.add(Point(1, 2));
    points.add(Point(3, 4));
    print(points, points.top());

  Output:
    [{x: 1, y: 2}, {x: 3, y: 4}] {x: 3, y: 4}

iterative DFS with Stack
  A Stack can replace recursion in depth-first traversal.

  Example:
    List<List<int>> graph = [[1, 2], [3], [3], []];
    List<int> visited = [0, 0, 0, 0];
    List<int> order;
    Stack<int> pending;
    pending.add(0);
    while (len(pending) > 0) {
        int node = pending.pop();
        if (visited[node] == 0) {
            visited[node] = 1;
            order.add(node);
            for (int next in graph[node]) {
                pending.add(next);
            }
        }
    }
    print(order, delim = " ");
    print(pending);

  Output:
    0 2 3 1
    []

BFS with Queue
  A Queue naturally implements breadth-first traversal.

  Example:
    List<List<int>> graph = [[1, 2], [3], [3], []];
    List<int> visited = [1, 0, 0, 0];
    List<int> order;
    Queue<int> pending;
    pending.add(0);
    while (len(pending) > 0) {
        int node = pending.pop();
        order.add(node);
        for (int next in graph[node]) {
            if (visited[next] == 0) {
                visited[next] = 1;
                pending.add(next);
            }
        }
    }
    print(order, delim = " ");
    print(pending);

  Output:
    0 1 2 3
    []

sliding window maximum with Deque
  A Deque of indexes supports an O(n) sliding-window maximum.

  Example:
    List<int> values = [1, 3, -1, -3, 5, 3, 6, 7];
    List<int> answer;
    Deque<int> candidates;
    int width = 3;
    for (int i in range(len(values))) {
        while (len(candidates) > 0 && candidates.front() <= i - width) {
            candidates.popFront();
        }
        while (len(candidates) > 0 && values[candidates.back()] <= values[i]) {
            candidates.popBack();
        }
        candidates.addBack(i);
        if (i >= width - 1) {
            answer.add(values[candidates.front()]);
        }
    }
    print(candidates);
    print(answer);

  Output:
    [7]
    [3, 3, 5, 5, 6, 7]

Type inference
--------------

var int inference
  `var` may infer scalar types from normal expressions.

  Example:
    int x = 1;
    var y = x * 2;
    print(y);

  Output:
    2

var string slice and char index
  `var` may infer both string slices and indexed chars.

  Example:
    string s = "pineapple";
    var s2 = s[1:4];
    var ch = s[1];
    print(s2);
    print(ch);

  Output:
    ine
    i

var from typed conversions
  `var` may infer container types from expressions whose result type is already known.

  Example:
    Map<int, int> counts = {3:9, 1:4};
    var entries = List(counts);
    print(entries);

  Output:
    [(1,4), (3,9)]

var in range foreach
  `for (var x in range(...))` infers the loop variable as `int`.

  Example:
    int total = 0;
    for (var x in range(1, 4)) {
        total += x;
    }
    print(total);

  Output:
    6

var complex program
  `var` works naturally across scalars, strings, containers, and range loops in one flow.

  Example:
    int x = 1;
    string s = "pineapple";
    Map<int, int> counts = {3:9, 1:4};
    var twice = x * 2;
    var piece = s[1:4];
    var ch = s[1];
    var entries = List(counts);
    var up = List(range(4));
    var down = Set(range(5, 1));
    var total = 0;
    for (var i in range(1, 4)) {
        total += i;
    }
    print(twice);
    print(piece);
    print(ch);
    print(entries);
    print(up);
    print(down);
    print(total);

  Output:
    2
    ine
    i
    [(1,4), (3,9)]
    [0, 1, 2, 3]
    {2, 3, 4, 5}
    6

Set, Map, and Pair literals
---------------------------

set literal
  Set literals use braces, deduplicate values, and keep sorted iteration order.

  Example:
    Set<int> seen = {3, 1, 2, 3};
    print(seen);
    print(seen.remove(2));
    print(2 in seen);

  Output:
    {1, 2, 3}
    2
    0

print set with delimiter
  Sets support print(..., delim = ...) in sorted order.

  Example:
    Set<int> seen = {3, 1, 2};
    print(seen, delim = ',');

  Output:
    1,2,3

print set with delimiter and end
  Sets support custom delimiters and custom end text together.

  Example:
    Set<int> seen = {3, 1, 2};
    print(seen, delim = " << ", end = "*\n");

  Output:
    1 << 2 << 3*

map literal
  Map literals use braces with key:value entries and print in key order.

  Example:
    Map<int, int> counts = {2:7, 1:4};
    print(counts);
    print(counts[2]);

  Output:
    {1:4, 2:7}
    7

map literal of nested types
  Map literals support nested Set values and print them organically too.

  Example:
    Map<int, Set<int>> groups = {2:{5, 4}, 1:{3, 1}};
    print(groups, end = "!\n");

  Output:
    {1:{1, 3}, 2:{4, 5}}!

len set and map
  len(...) also works on Set and Map values.

  Example:
    Set<int> seen = {7, 1, 4};
    Map<int, int> counts = {3:9, 1:2};
    print(len(seen), len(counts));

  Output:
    3 2

min and max on set
  min(set) and max(set) return the smallest and largest set values.

  Example:
    Set<int> seen = {7, 1, 4};
    print(min(seen), max(seen));

  Output:
    1 7

min and max on map keys
  min(map) and max(map) return the smallest and largest keys.

  Example:
    Map<int, int> emptyAdj;
    Map<int, Map<int, int>> graph = {4:{1:8}, 2:{9:3}, 7:emptyAdj};
    print(min(graph), max(graph));

  Output:
    2 7

manual inorder traversal on set
  prev(...), next(...), min(...), and max(...) can manually walk an ordered
  Set even when the queried value is not itself present.

  Example:
    Set<int> seen = {2, 5, 9, 13};
    int cur = min(seen);
    print(cur, end = " ");
    cur = seen.next(cur);
    print(cur, end = " ");
    print(seen.prev(12), end = " ");
    print(max(seen));

  Output:
    2 5 9 13

manual inorder traversal on map keys
  Map.prev(...), Map.next(...), min(map), and max(map) operate on keys.

  Example:
    Map<int, int> counts = {2:8, 5:1, 9:4};
    int cur = min(counts);
    print(cur, end = " ");
    cur = counts.next(cur);
    print(cur, end = " ");
    print(counts.prev(8), end = " ");
    print(max(counts));

  Output:
    2 5 5 9

map and set hasNext and hasPrev
  hasNext(key) and hasPrev(key) report whether a present Map key or Set value
  has a neighboring item in sorted order.

  Example:
    Set<int> seen = {2, 5, 9};
    Map<int, int> counts = {2:7, 5:1, 9:4};
    print(seen.hasPrev(2), seen.hasNext(2), seen.hasNext(9));
    print(counts.hasPrev(5), counts.hasNext(5), counts.hasPrev(2));

  Output:
    0 1 0
    1 1 0

membership in set and map
  Membership on Set and Map uses ordered lookup on the element or key type.

  Example:
    Set<int> seen = {2, 5, 9};
    Map<int, int> counts = {3:7, 8:1};
    print(5 in seen, 4 in seen);
    print(8 in counts, 2 in counts);

  Output:
    1 0
    1 0

foreach on set and map
  foreach loops also work on Sets and Maps. Maps yield Pair<key, value>
  elements in key order.

  Example:
    Set<int> seen = {5, 1, 3};
    Map<int, int> counts = {4:7, 1:2};
    for (int x in seen) {
        print(x, end = " ");
    }
    print("");
    for (Pair<int, int> entry in counts) {
        print(entry, end = " ");
    }

  Output:
    1 3 5 
    (1,2) (4,7) 

pair declaration and indexing
  Pair<K, V> declarations support zero-based indexing at [0] and [1].

  Example:
    Pair<int, int> point = (4,9);
    print(point[0], point[1]);

  Output:
    4 9

pair reassignment
  Pairs may be reassigned like other CP++ values.

  Example:
    Pair<int, int> point;
    point = (3,5);

simulate map with Set<Pair>
  A Set<Pair<int, int>> can simulate a tiny Map<int, int> using helper
  functions, pair indexing, set membership updates, and for-in over sets.

  Example:
    int mapGet(Set<Pair<int, int>> entries, int key) {
        for (Pair<int, int> entry in entries) {
            if (entry[0] == key) {
                return entry[1];
            }
        }
        return 0;
    }

    void mapPut(Set<Pair<int, int>> entries, int key, int value) {
        Pair<int, int> old = (0,0);
        bool found = false;
        for (Pair<int, int> entry in entries) {
            if (entry[0] == key) {
                old = entry;
                found = true;
            }
        }
        if (found) {
            entries.remove(old);
        }
        entries.add((key,value));
    }

    int mapRemove(Set<Pair<int, int>> entries, int key) {
        for (Pair<int, int> entry in entries) {
            if (entry[0] == key) {
                entries.remove(entry);
                return entry[1];
            }
        }
        return 0;
    }

        int type = input();
        int key = input();

            int value = input();
            mapPut(entries, key, value);
        } else if (type == 2) {
            print(mapGet(entries, key));
        } else {
            print(mapRemove(entries, key));
        }
    }

LinkedList class synthesis output
  Class methods can compose recursive Node values into a linked list with
  indexed add, remove, and get operations.

  Example:
    class Node {
        int val;
        Node next;
    }
    class LinkedList {
        Node head;
        int size;
        void add(int x, int loc) {
            if (loc == 0) {
                head = Node(x, head);
                size++;
                return;
            }
            if (loc == 1) {
                head.next = Node(x, head.next);
                size++;
            }
        }
        int remove(int loc) {
            if (loc == 0) {
                int removedHead = head.val;
                head = head.next;
                size--;
                return removedHead;
            }
            int removedValue = head.next.val;
            head.next = head.next.next;
            size--;
            return removedValue;
        }
        int get(int loc) {
            if (loc == 0) {
                return head.val;
            }
            return head.next.val;
        }
    }
    LinkedList list = LinkedList(NULL, 0);
    list.add(10, 0);
    list.add(30, 1);
    list.add(20, 1);
    print(list.get(0), list.get(1), list.size);
    print(list.remove(1), list.get(1), list.size);

    10 20 3
    20 30 2

DoublyLinkedList class recursive links output
  Shared class links allow a doubly linked list to maintain both next and
  prev links while add, remove, and get update the list consistently.

  Example:
    class Node {
        int val;
        Node next;
        Node prev;
    }
    class DoublyLinkedList {
        Node head;
        Node tail;
        int size;
        void add(int x, int loc) {
            if (size == 0) {
                Node node = Node(x, NULL, NULL);
                head = node;
                tail = node;
                size++;
                return;
            }
            if (loc == 0) {
                Node node = Node(x, head, NULL);
                head.prev = node;
                head = node;
                size++;
                return;
            }
            if (loc == size) {
                Node node = Node(x, NULL, tail);
                tail.next = node;
                tail = node;
                size++;
                return;
            }
            Node current = head;
            int index = 0;
            while (index < loc - 1) {
                current = current.next;
                index++;
            }
            Node node = Node(x, current.next, current);
            current.next.prev = node;
            current.next = node;
            size++;
        }
        int remove(int loc) {
            Node current = head;
            int index = 0;
            while (index < loc) {
                current = current.next;
                index++;
            }
            int removed = current.val;
            if (current.prev == NULL) {
                head = current.next;
            } else {
                current.prev.next = current.next;
            }
            if (current.next == NULL) {
                tail = current.prev;
            } else {
                current.next.prev = current.prev;
            }
            size--;
            return removed;
        }
        int get(int loc) {
            Node current = head;
            int index = 0;
            while (index < loc) {
                current = current.next;
                index++;
            }
            return current.val;
        }
    }
    DoublyLinkedList list = DoublyLinkedList(NULL, NULL, 0);
    list.add(10, 0);
    list.add(30, 1);
    list.add(20, 1);
    print(list.get(0), list.get(1), list.get(2), list.size);
    print(list.head.next.prev.val, list.tail.prev.val);
    print(list.remove(1), list.get(1), list.head.next.prev.val, list.size);

  Output:
    10 20 30 3
    10 20
    20 30 10 2
