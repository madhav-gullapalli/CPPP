CP++ Error Inventory
====================

Scope: every `error:` headline currently documented in errors.txt, deduplicated
within each documentation section. There are 229 documented error occurrences
and 196 globally unique headline texts. Concrete variable names, type names,
method names, and values are shown exactly as they appear in the current
examples.

`help: (none)` means the diagnostic currently has no explicit `= help:` line.
Primary-span labels are not counted as help suggestions.
